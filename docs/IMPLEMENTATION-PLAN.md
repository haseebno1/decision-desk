# Implementation Plan

## Phase 0 — Foundation

- Initialise React + TypeScript + Vite
- Configure styling
- Establish folder structure
- Add linting/type checking
- Create basic app shell

### Done when

The project builds and displays the application shell.

## Phase 1 — Decision Capture

- Home screen
- New Decision flow
- Title/description
- Category
- Stake
- Options
- Draft state

### Done when

A user can create and edit a decision locally.

## Phase 2 — Criteria & Scoring

- Criteria creation
- Weight controls
- Option score matrix
- Weighted score calculation
- Validation

### Done when

Two or more options can be compared mathematically.

## Phase 3 — Recommendation

- Recommendation engine
- Explanation
- Trade-off detection
- Close-score handling
- Result screen
- Commit action

### Done when

The user receives a transparent recommendation based on entered data.

## Phase 4 — History

- Persist completed decisions
- Timeline
- Search
- Filters
- Detail view

### Done when

Past decisions are accessible after reload.

## Phase 5 — Patterns

- Aggregate metrics
- Most-used criteria
- Category breakdown
- Stake breakdown
- Decision-time statistics
- Basic descriptive insights

### Done when

The user can see patterns across decisions.

## Phase 6 — Outcome Review

- Expected outcome
- Actual outcome
- Satisfaction
- Would choose again
- Outcome comparison

### Done when

Users can learn from previous decisions.

## Phase 7 — AI Adapter

- Provider interface
- Mock provider
- Optional external provider
- Clarifying questions
- Criteria suggestions
- Summaries

### Done when

AI can enhance the workflow without becoming a hard dependency.

## Phase 8 — Polish

- Accessibility audit

- Empty states
- Loading states
- Error handling

- README update

## Phase 9 — Release

- Production build
